# نتائج اختبار الموقع التسويقي SSR

> **البيئة:** محلية لتطبيق Next.js مع بيانات Supabase Staging.  
> **تاريخ التحقق:** 19 أغسطس 2026.

| الاختبار | النتيجة | الملاحظة |
|---|---|---|
| بناء Next.js | ناجح | الصفحة الرئيسية، صفحات قانونية، Sitemap، المعاينة، وواجهة إبطال التخزين المؤقت بُنيت بنجاح. |
| اختبارات مخططات المحتوى | 3/3 ناجحة | تتحقق من Hero صالح، رفض Hero ناقص، ورفض SEO غير مكتمل. |
| عرض SSR محلي | ناجح | ظهر عنوان الصفحة والأقسام العشرة والتنقل والأسئلة الشائعة وروابط SaaS في HTML المعروض. |
| اتصال المحتوى المنشور | ناجح | دالة Staging العامة أعادت حمولة صفحة `home` مع 10 أقسام. |
| عزل اللغات | ناجح | العربية منشورة؛ الإنجليزية بلا نسخة منشورة وتعيد `null` كما هو متوقع. |
| صلاحية إبطال التخزين المؤقت | ناجح | الطلب بلا سر أعاد 401، والطلب الموثق محليًا أعاد 200. |
| بناء Vite | ناجح | دُمجت شاشة Super Admin ومكتبة الوسائط دون خطأ في حزمة SaaS. |
| انحدار تطبيق Vite | ناجح | 298 اختبارًا ناجحًا. |
| صفحة الخصوصية SSR | ناجح | ظهر العنوان والنص القانوني وزر العودة باللغة العربية. |
| عزل جداول CMS عن المفتاح العام | ناجح | طلب REST مباشر لجداول `marketing_pages` أعاد `200 []` تحت RLS. |
| واجهة المحتوى العامة المقصودة | ناجح | RPC `marketing_public_page` أعاد 10 أقسام منشورة للمفتاح العام. |

## ملاحظات جاهزية

لا توجد بيانات باقات نشطة في Staging، لذلك يعرض قسم التسعير رسالة انتظار بدل اختراع باقات أو أسعار داخل CMS. كما أن اختبارات نشر المسودة والمعاينة من الواجهة تتطلب حساب Super Admin فعليًا في Staging؛ دوال الخادم وسياسات التفويض موجودة، لكن لم يُنشأ حساب اختبار جديد.
