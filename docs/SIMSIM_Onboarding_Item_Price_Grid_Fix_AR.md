# SIMSIM — إصلاح تداخل حقل السعر في بطاقة الصنف

**إعداد:** Manus AI  
**النطاق:** تخطيط حقل السعر في بطاقة الصنف المحدد ضمن مرحلة «اختر أصنافك» في Onboarding.

## السبب الجذري

الإصلاح السابق فصل حقل السعر عن معلومات الصنف، لكنه أبقى وحدة العملة كعنصر `position: absolute` داخل حاوية RTL، بينما حقل الإدخال نفسه كان `direction: ltr`. في هذا السياق قد يشير `inset-inline-end` إلى الجهة المقابلة للمساحة التي حُجزت لها في `padding`، فيظهر تداخل بصري بين قيمة السعر ووحدة العملة على الهاتف.

## الإصلاح

تم حذف الطبقة المطلقة بالكامل واستبدالها بشبكة سعر صريحة:

```text
[ حقل الرقم المرن minmax(0, 1fr) ] [ وحدة العملة بعرض ثابت ]
```

الحقل ووحدة العملة الآن عنصران في أعمدة مستقلة. الحقل يستخدم `minmax(0, 1fr)` كي ينكمش بلا خروج عند أضيق عرض، بينما تستخدم وحدة العملة عرضًا أدنى ثابتًا `58px`. لا توجد إزاحة absolute أو padding تعويضي، ولذلك لا توجد مساحة يمكن أن تتصادم فيها القيمة والعملة.

## ما لم يتغير

لم يتغير منطق السعر الحقيقي أو `itemPrices` أو تحقق السعر أو عملية الحفظ أو قاعدة البيانات أو Supabase أو API أو RLS.
